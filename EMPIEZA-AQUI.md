# Empieza aquí

Tienes esta carpeta en tu ordenador. Ahora ábrela con Claude Code y pégale esto:

```
/arrancar
```

Eso es todo. Él te va preguntando lo que necesita y te deja el estudio montado.

---

## Si prefieres no usar comandos

Pega este texto tal cual en Claude Code, dentro de esta carpeta:

```
Lee el README.md y el CLAUDE.md de esta carpeta para saber cómo trabajamos.

Luego móntame el estudio:

1. Entrevístame para crear mi CLAUDE.local.md: nombre, colegio, número de
   colegiado, municipios donde trabajo habitualmente, tipo de encargo más
   frecuente, y mis manías de redacción. Una pregunta cada vez.

2. Mira qué hay en normativa/ y en estilo/ y dime qué me falta por colocar.

3. Cuando esté, dime en cinco líneas qué puedo pedirte a partir de ahora.

No redactes ningún documento hasta que el CLAUDE.local.md exista.
```

## Cuando te avise de que hay novedades

```
/actualizar
```

O, en texto: *«Haz git pull y cuéntame qué ha cambiado según la BITACORA.»*

## Las tres reglas que no cambian

1. Una conversación por tarea. Redactar y revisar, en conversaciones distintas.
2. Documento adjunto siempre. Lo que no le adjuntas, se lo inventa con buena letra.
3. Lo que firmas, lo lees entero. **La IA redacta, tú firmas.**

# Normativa

Aquí van tus PDFs. **No se suben al repositorio** y así debe seguir: pesan mucho,
cada estudio trabaja en municipios distintos, y el repo se volvería inmanejable.

Organización sugerida:

```
normativa/
├─ cte/              DB-SI, DB-SUA, DB-HE, DB-HS, DB-HR, DB-SE...
├─ autonomica/       habitabilidad, urbanística, accesibilidad
├─ municipal/        una carpeta por municipio
└─ colegio/          modelos, licencias, documentos colegiales
```

## Dos cosas importantes

**PDF con texto seleccionable.** Si es un escaneo, primero pásale un OCR. Un PDF
que es una foto de un texto no se puede citar literalmente, y sin cita literal
todo el sistema de verificación se cae.

**Solo lo que aplica.** No cargues los seis DB en una conversación «por si
acaso»: empeora las respuestas y consume el límite de uso mucho antes.

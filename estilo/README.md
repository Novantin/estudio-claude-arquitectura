# Estilo

Aquí vive `GUIA-DE-ESTILO.md`, que no está en el repositorio porque es tuya.

Se genera una sola vez, a partir de tus memorias antiguas:

```
Te adjunto tres memorias de proyecto redactadas por mí.

Analízalas como un editor y escríbeme una GUÍA DE ESTILO de una página que sirva
para que otro redactor escriba igual que yo. Cubre: persona verbal y voz;
longitud media de frase y párrafo; léxico característico —qué términos uso
siempre y cuáles evito—; estructura y numeración de apartados que repito; cómo
introduzco las citas normativas; muletillas propias que aparecen en las tres; y
qué NO aparece nunca en mis textos.

Cítame ejemplos literales para cada punto. No opines sobre si mi estilo es
bueno: descríbelo.

Guárdala en estilo/GUIA-DE-ESTILO.md
```

Revísala a mano antes de darla por buena. Es lo que hace que los borradores
suenen a ti y no a máquina.

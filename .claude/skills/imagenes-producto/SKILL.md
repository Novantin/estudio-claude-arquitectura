# Imágenes de producto

Para la marca de camisetas. Nada que ver con el trabajo técnico del estudio:
carpeta aparte, criterio aparte.

## El caso de uso real

Una sesión de fotos son diez minutos y da para un post. El objetivo es
**exprimir cada foto**: de una toma, material para varios días.

| Lo que se pide | Qué hace |
|---|---|
| «Sácame tres parecidas» | Mismo sujeto y prenda, distinta pose, encuadre y luz |
| «Gírala para que se vea la espalda» | La misma camiseta por detrás, con el estampado trasero |
| «Sácala en verde» | Mismo diseño, otro color de prenda, todo lo demás igual |

## Procedimiento

1. Sube la foto original como referencia de imagen.
2. Describe **qué tiene que quedarse igual** antes que lo que cambia: el
   estampado, su posición y escala, el tipo de prenda, la persona, la luz.
3. Genera de una en una o en lote, según cuántas variaciones hagan falta.
4. Guarda en la carpeta de la marca, nombradas por campaña y fecha.

## Reglas

- **El estampado no se reinterpreta.** Si el modelo lo redibuja, se descarta la
  imagen: es el producto que se vende.
- Nada de texto generado sobre la prenda. Los modelos escriben letras falsas y
  se nota.
- Si sale una persona reconocible, que sea con su permiso.
- Una imagen de producto que no representa fielmente lo que se envía al cliente
  no se publica. Eso no es criterio estético, es no vender una cosa por otra.

# Empieza aquí

En el taller montamos todo en el ordenador del formador. Esto es el despliegue en
el tuyo: tres pasos y ya está funcionando.

## 1. Traer la carpeta

En una terminal:

```bash
git clone https://github.com/Novantin/estudio-claude-arquitectura.git estudio-claude
```

## 2. Meter lo tuyo

Copia dentro de `estudio-claude` la carpeta **`entrega`** que te has llevado del
taller, tal cual, sin abrirla ni ordenarla.

Copia también tus PDFs de normativa dentro de `normativa/`.

## 3. Arrancar

```bash
cd estudio-claude
claude
```

Y dentro, escribe:

```
/arrancar
```

Coloca cada cosa en su sitio, comprueba que no falta nada y te dice qué puedes
pedirle. Tarda un minuto y no gasta casi nada: el trabajo ya estaba hecho.

---

## Cuando te avisen de que hay novedades

```
/actualizar
```

Trae las mejoras del kit y te cuenta qué ha cambiado. Tus cosas no se tocan
nunca: `CLAUDE.local.md`, `encargos/`, `normativa/` y tu guía de estilo están
fuera del control de versiones a propósito.

## Las tres reglas que no cambian

1. Una conversación por tarea. Redactar y revisar, en conversaciones distintas.
2. Documento adjunto siempre. Lo que no le adjuntas, se lo inventa con buena letra.
3. Lo que firmas, lo lees entero. **La IA redacta, tú firmas.**

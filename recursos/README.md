# Recursos

Los materiales de apoyo del encargo en curso: catálogos de carpintería, fichas
técnicas, fotos de la visita, capturas de catastro.

**No se suben al repositorio.** Van aquí para que Claude pueda abrirlos y leerlos
—incluidas las imágenes: sabe interpretar una ficha de catálogo sin que se la
expliques— pero no para compartirlos.

No los pegues dentro de `INFORMACION-OBRA.md`. Ese archivo es texto; aquí van los
archivos. Referéncialos por nombre desde la tabla de carpintería.

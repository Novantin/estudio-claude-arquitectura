# Encargos

Una carpeta por encargo. **No se suben al repositorio**: aquí hay datos de
cliente.

```
encargos/
└─ 2026-014-reforma-calle-mayor/
   ├─ FICHA-ENCARGO.md      ← lo primero que se genera
   ├─ entrada/              notas de visita, fotos, planos, catastro, correos
   └─ salida/               memoria.docx, auditoria.xlsx, informes
```

En `entrada/` va el material tal cual llegue, sin ordenar. Ese desorden es el
punto de partida normal y Claude trabaja bien con él.
